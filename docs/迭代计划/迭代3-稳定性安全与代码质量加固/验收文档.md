## 0. 验收原则

1. **fail-closed**：工具缺失、命令未执行、输出为空、数据库身份不明，一律记为 `NOT_RUN`/`BLOCKED`，不得记为通过。
2. **证据可复算**：每条 AC 附命令、真实输出、日期、执行环境；历史证据只作参考。
3. **修复前必红**：每个 P0/P1 回归测试必须先在修复前失败，修复后通过；只保留一次失败日志作为证据。
4. **环境隔离**：测试使用 `APP_ENV=testing TESTING=true REDIS_URL= SENTRY_DSN=`；不得从 `.env` 加载凭据；数据库只写一次性 schema。
5. **范围诚实**：本轮通过不代表迭代2的 `SOURCE_VERIFIED`/`DEPLOYMENT_VERIFIED`，也不代表 350 模型完成。

---

## 1. 验收状态定义

| 状态 | 含义 |
|---|---|
| PASS | 命令 exit 0，输出与判据逐项一致，证据已归档 |
| FAIL | 命令非 0 或断言失败 |
| BLOCKED | 缺少环境/凭据/数据库授权，未执行 |
| NOT_RUN | 未执行，不得以“静态看起来没问题”替代 |
| PARTIAL | 部分子项通过；不得汇总为 PASS |

## 2. AC 明细

### AC3-01 生产密钥校验

**判据**：`APP_ENV=production` 且 `SECRET_KEY` 未设置或等于默认值时，构造 `Settings` 必须失败；`APP_ENV=production` 仅写在 `.env` 时同样必须失败。

**命令**：

```bash
env -u SECRET_KEY APP_ENV=production python -c "from opendata.core.config import Settings; Settings(_env_file=None)"
# 期望：非 0，ValidationError
```

```bash
tmp=$(mktemp); printf 'APP_ENV=production\n' > "$tmp"
env -u APP_ENV -u SECRET_KEY python -c "from opendata.core.config import Settings; Settings(_env_file='$tmp')"
# 期望：修复后非 0；修复前为 0（已复现）
```

**证据**：命令输出、退出码、日期、Python 版本。

### AC3-02 管理员初始化

**判据**：未设置 `ADMIN_DEFAULT_PASSWORD` 时，启动必须 fail-fast，或生成密码可通过 0600 文件被操作者一次性读取；日志不得出现密码片段。

**命令**：隔离数据库 + `APP_ENV=testing TESTING=true` 启动 `init_db()`。

**证据**：退出码、日志、文件权限（`stat -c '%a %n'`）、是否可登录。

### AC3-03 刷新令牌生命周期

**判据**：

1. 登出后，同一 refresh token 调 `/auth/refresh` 返回 401。
2. 刷新成功后，旧 refresh token 再使用返回 401。
3. 改密后，改密前签发的 access/refresh token 均失效。

**命令**：隔离 DB + `httpx.AsyncClient` 集成测试，显式节点。

**证据**：三次请求的状态码与响应体。

### AC3-04 API Key 授权

**判据**：通过 `/keys` 创建仅含 domain scope 的 key，能读取该 domain 的授权数据集；跨 domain 或未授权 operation 返回 403。

**命令**：集成测试，构造授权 grant 文件与数据集。

**证据**：状态码、返回数据集 ID。

### AC3-05 并发冲突

**判据**：两个并发注册、两个并发 `init_db`、两个并发 rotate 同一 key，不得出现未捕获 500；冲突返回 400/409 且会话可继续使用。

**命令**：`asyncio.gather` 并发测试；隔离 DB。

**证据**：状态码集合、日志中无 `Traceback`、后续请求成功。

### AC3-06 写入错误可见

**判据**：非重复键错误（类型错误、超长、约束违反）必须抛出；重复键按 upsert 处理；不得静默丢行。

**命令**：仓储单测，临时 schema。

**证据**：异常类型、行数、失败批次日志。

### AC3-07 列冲突与截断

**判据**：DataFrame 含 `id`/`row_hash`/`created_at` 时明确拒绝或重命名；超出声明长度的值不被静默截断。

**命令**：单测，构造冲突列与超长值。

**证据**：抛出的领域错误、DDL、写入值。

### AC3-08 行哈希黄金向量

**判据**：`None`/`"None"`/`"nan"`、含 `|` 的值、不同类型同值不得产生相同 row_hash。

**命令**：黄金向量单测。

**证据**：输入/期望哈希/实际哈希。

### AC3-09 重试成功判定

**判据**：脚本返回 `success=False` 时，重试执行记录为 `FAILED`；成功时 `rows_processed` 非空且与结果一致。

**命令**：单测 mock `DataService.execute_script` 返回失败/成功字典。

**证据**：`TaskExecution.status`、`rows_after`、重试队列。

### AC3-10 导出公式注入

**判据**：XLSX/CSV 中以 `=`、`+`、`-`、`@` 开头的字符串单元格不形成公式。

**命令**：导出后用 `openpyxl.load_workbook(data_only=False)` 断言 `cell.data_type != 'f'`。

**证据**：单元格类型、原始值。

### AC3-11 水位回放

**判据**：未知 `since_batch_id` 返回最近 `limit` 条（按 seq 升序），跨域 batch 不解析为外部 seq。

**命令**：仓储测试，构造 5 条批次。

**证据**：返回 batch_id 列表。

### AC3-12 告警升级

**判据**：同一指纹第二次出现且 `diff_rate` 超过 `RATE_SPIKE_FACTOR` 时，`level=critical`。

**命令**：`AlertDecider` 单测两次 `decide`。

**证据**：两次 `AlertDecision`。

### AC3-13 运行关闭门禁

**判据**：`ReviewedRuntime.close()` 后调用 `dispatcher.dispatch_backfill_execution` 被拒绝；无 `api` 角色时同样拒绝。

**命令**：单测。

**证据**：异常类型/消息。

### AC3-14 触发器校验

**判据**：interval 全零/负值、date 缺失 `run_date` 抛配置错误；pending job 的 `_job_to_dict` 不抛 `AttributeError`。

**命令**：`SchedulerService` 单测。

**证据**：异常/字典输出。

### AC3-15 调度执行 ID

**判据**：`trigger_task` 返回的 `execution_id` 能在 `TaskExecution` 中查到；同一秒两次触发不产生相同 id。

### AC3-16 WebSocket 广播

**命令**：并发 WS 测试，慢消费者 + 快消费者。
