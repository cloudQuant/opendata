=== [4] 结论 ===
  CI  : python 3.11 + pandas 3.0.6 + numpy 2.4.6 + pytest 9.1.1（三次红都一样）
  本机: python 3.13.5 + pandas 2.3.1 + numpy 2.3.1 + pytest 8.4.1
  项目没有依赖锁（约束全是 >=），CI 每次解析到当时的最新版，所以「本机绿」与「CI 绿」现在不是同一套依赖下的同一件事。
  AC-6 的录制夹具由 pandas 2.x 产生（reference.csv.gz 存的是 ...40997），CI 用 pandas 3.0.6 复算搬运层，
  同一串源文本（新浪给的 18 位 item_value 字符串）给出相邻 double（...41，差 1 ULP、rel=1.4e-16）。
  => 红不是搬运层失真，而是「跨大版本复算录制文本」本身带末位漂移；判据要按 AC-6 写的「浮点在容忍度内」判。
  => 记一笔没做的：把 CI/本机钉到同一套依赖（加锁 + ci.yml 安装锁）是更大的决定，本轮不动，等确认。
