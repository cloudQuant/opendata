# C64 仿射复权实现设计

日期：2026-09-30；用户已明确确认采用 `scale × 原价 + offset`，保留未复权价和旧因子溯源，补充现金分红与送转事件链。

## 数学口径

单个事件的正向变换为 `T(p) = (p - c + r × R) / (1 + b + r)`。
`c` 为每股现金红利，`b` 为每股送转比例，`r` 为每股配股比例，`R` 为配股价格；
因此 `a = 1 / (1 + b + r)`，`o = (r × R - c) / (1 + b + r)`，`T(p) = a × p + o`。
一般除权除息参考价公式可见[上交所交易规则第 4.3.2 条](https://www.sse.com.cn/lawandrules/sselawsrules2025/fund/trading/c/c_20260424_10817739.shtml)及[深交所说明](https://www.szse.cn/www/investor/knowledge/t20181017_555756.html)。
跨事件历史复合与查询锚点是本项目的实现选择，不据此宣称与所有供应商序列一致。

复合顺序：`(a2, o2) ∘ (a1, o1) = (a2 × a1, a2 × o1 + o2)`。
前复权对当日严格之后、截至该标的最后已知交易日的事件按时间正向复合；
后复权对该标的首个已知交易日之后、截至当日的事件复合逆变换。
最新日前复权与最早日后复权系数均为 `(1, 0)`。

手算检查：先每股现金分红 10，再每股送转 1，前复权事件链为 `p / 2 - 5`；
后复权链为 `2 × p + 10`。倒置复合会产生不同结果，必须有独立断言。
纯现金分红前复权为 `p - c`，不是在某个参考价上拟合一个乘法因子。

## 存储与兼容

| 字段 | 语义 |
|---|---|
| `qfq_factor`、`hfq_factor` | 保留旧乘法算法的数值及溯源 |
| `qfq_scale`、`qfq_offset` | 新前复权系数 |
| `hfq_scale`、`hfq_offset` | 新后复权系数 |
| `adjustment_version` | `affine-v1` 标识新系数；NULL 或 `legacy-multiplicative-v1` 表示旧行 |
| `legacy_source` | 已有旧因子的原 source；新行的旧算法来源标记 |

旧行新系数均为 NULL，继续使用旧算法。新行必须明确为 `affine-v1` 且四项系数完整，
scale 为正、所有数值有限；部分填充、未知版本及非有限值拒绝使用，不能默认为单位变换。
已有行的旧因子值及原来源保留；新行才生成旧算法读数并另存新系数，不把旧因子重新解释为 scale。

`dwd_stock_daily` 始终保存未复权 OHLC；查询和导出仅在明确请求 qfq/hfq 时合成。
成交量与成交额不变，`adjust=none` 不变；JSON/CSV 保持既有 OHLC 列和 adjust 参数契约。
旧因子与新系数在 stock_adjust 表保留，未复权价可由同一查询的 `adjust=none` 获取。

历史数据迁移 0005 固定为原有列形状，避免随当前模型漂移；0007 只增加六个可空列，
不覆写旧值。分别检查从头升级与既有 0006 升级，降级只移除新增列。

## 事件、窗口与运行入口

ODS 的 `event_key` 保留。同标的同除权日多个条目可能是修订或不同权益记录；
没有能证明组合顺序的输入时拒绝重建并保持零写入。单个条目内的现金、送转、配股正常组合。
事件无前收、非有限输入、负比例及不合理参考价均拒绝。

事件数据自 1991 年开始，但日线仅约十年；事件本身不能补出缺失的原价。
重建读取完整已知日线，以各标的真实首尾 bar 为基准，基准外及没有 bar 的事件单独计数，
不声称覆盖缺失历史。窗口重建在该基准计算后只写指定窗口。新增事件可能改变此前全部前复权值，
因此运维需执行全量重建；窗口重建不能证明历史所有行已更新。
新增重建命令默认 dry-run，只有明确 `--apply` 才写入；不接受任意连接串或表名。

同一标的、同一请求窗口的实际行情不能混用旧乘法版本和 `affine-v1`。
检查应覆盖分页及 CSV 的全部批次；不同标的可各自使用不同版本，窗口外或未匹配行情的因子不参与该检查。
局部重建后，覆盖新旧行的复权请求拒绝执行；未复权查询仍可使用，完成全量重建后恢复复权查询。
