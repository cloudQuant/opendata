## 全树 A1 面：`make lint` 的实测读数与上面那条 scope_note 的更正

上面 scope_note 把 `make lint` 说成"被门禁的那个面"，这句不准，按 Makefile 自己写的更正：
`lint:` 目标在 Makefile:44 的注释下 —— "Developer views (full tree; A1 debt is expected here)"。
门禁那一条是 `a2-check: python scripts/quality/a2_check.py`（Makefile:41-42），规则是 A2
「碰到才算数」，不是全树零违例。所以本文件上面那些 per-file exit=0 是 A2 那一侧的读数，
全树的 157 是 A1 欠量，两件事不冲突。全树实测（提交前跑，ruff 0.15.20，PATH 与 py313 环境同版本）：

```

scripts/quality 下的 13 条属于既往波的其它分片：intrinio/market.py 4、fmp/rows_c.py 4、
  federal_reserve/rows_a.py 2、econdb/rows_a.py 2、cboe/historical.py 1 —— 都不在本波载荷里
抽样核过 `opendata/api/executions.py` 与 HEAD 逐字节相同，即这 157 是 HEAD 就有的，不是本波造出来的
```

本波载荷与这 50 枚的交集为空：`overlap_with_payload=0`。但这条 0 第一次取的时候是假的 ——
`grep -oE '^[a-zA-Z_][^: ]*\.py'` 在 ruff 的输出上一枚文件都没匹配到（路径在 `--> path:line:col`
那一行，且前面有缩进），产出的清单是空文件，空清单与任何东西求交当然为 0。改成
`grep -oE '\-\-> [^:]+:[0-9]+:[0-9]+'` 再剥掉行列，distinct_files 从 0 变 50，交集仍是 0。
同一批里还有一条同族：`git status --porcelain -- $(cat 空清单)` 展开成不带路径的 `git status`，
读出 `dirty_among_them=360` —— 那不是"360 枚 lint 文件是脏的"，那是我传了个空参数。
两条都按"分母要先非空、参数要先解析出来"重取。
