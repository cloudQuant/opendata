# A0.3 改名验证证据

date: 2026-09-22
依据：AC-1（品牌/包名）、实施计划 A0.3

## 方法

对`opendata/`、`tests/`、`alembic/`、`scripts/` 与根配置文件，逐个文件与重构起点副本
`../akshare_web` 比对：把新文件的 `opendata` 还原为 `app` 后，要求与参照**逐字节相等**。
这样任何"非改名"的改动都会被暴露出来。

## 结论 1：纯改名验证（A0.3 执行时刻）

```text
$ python3 <normalise-and-compare vs ../akshare_web>
checked files            : 103
unexpected differences   : 0
```

即改名本身是**纯机械替换**，无额外副作用。
