# ---- 取证纪律（本轮在这份档案上自己踩到的两个坑）----
# 1) 上一版这份档案把 brand 的退出码写成 `BRAND_EXIT=${PIPESTATUS[0]:-$?}`，而 shell 是 zsh：
#    zsh 的管道状态数组是 $pipestatus（1-indexed），${PIPESTATUS[0]} 取到空，`:-` 落到 $?，
#    于是那一行的 0 记的是 tail 的退出码，不是 check_brand 的。这一版改成 subprocess 直跑取 returncode，
#    并在下面登记：任何带管道的成员重跑都必须单独证明退出码来源。
# 2) brand-check 的完整 stdout（13 行 token 面 + 包引用面 + upstream 上下文）在此未裁剪保留，
#    上一版的 `| tail -3` 会把 'ok akshare_web …' 那 12 行丢掉，读者就无从核对 token 清单有没有变。
