Arms — docs/evidence/C150/gitleaks-counterfactual.py
-----------------------------------------------------
A throwaway git history is built from the nine real declarations plus three planted
variants; each config is read over that history. `[]` means nothing reported.

    arm              real_lines  one_char_longer  token_in_same_slot  generic_secret_in_same_slot
    shipped          []          generic-api-key  github-pat          generic-api-key
    without_c150     generic-api-key  generic-api-key  github-pat      generic-api-key
    default_rules    generic-api-key  generic-api-key  github-pat      generic-api-key

What each arm proves:

* `shipped` vs `without_c150` — the C150 regex is precisely what silences those nine
  declaration lines; remove that one line and all ten findings return. Nothing else in the
  allowlist is load-bearing for them (`default_rules` matches `without_c150` here).
* `one_char_longer` — appending a single character to three of the eight literals is
  reported again under the shipped config. The exemption is the literal list, not a
  `fixture-*` / `quota-*` value class, so a different value typed into the same slot does
  not inherit it.
* `token_in_same_slot` / `generic_secret_in_same_slot` — a planted credential in the very
  same `budget_quota_key=` / `PRINCIPAL =` / `run_key=` slot is still reported under the
  shipped config. As C75 measured, the prefixed `ghp_` form is reported by `github-pat`
  and never by `generic-api-key` even with every allowlist removed, so the honest reading
  of that arm is "still reported, by `github-pat`"; the unprefixed mixed-case secret in
  the same slot is reported by `generic-api-key` itself in all three arms.

Reviewer boundary
-----------------
This is a per-literal exemption for values that are already in history, not a value class
and not a path scoping. A real credential that happens to be *named* one of these eight
strings would be exempt from `generic-api-key` only — the specific rules (`github-pat`,
`aws-access-key-id`, ...) are untouched, as the `token_in_same_slot` arm shows.
