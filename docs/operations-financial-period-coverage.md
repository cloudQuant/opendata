# 财报报告期覆盖评估运维说明

`opendata.pipeline.financial_period_coverage.assess_financial_period_coverage` 是一个纯函数，用来对调用方明确提供的财报报告期槽位做保守分类。它不查询数据、发现标的或生成待采集报告期，也不代表财报完整性验收。

## 评估单位

每个槽位由精确身份和报告期组成：规范证券 `security_id`、数据源 `source_id`、源侧标的 `source_instrument_id`、报表类型 `income` / `balance` / `cashflow`、周期 `annual` / `quarterly`，以及日历日期 `report_period`。源侧身份到规范证券的 crosswalk 必须在该报告期有效。年度与季度是不同槽位，不能互相替代；同一槽位可以保留多个观察版本。

调用方必须显式传入希望评估的槽位和 `as_of_utc`。函数不会按上市日期、当前日期或相邻报告期推导槽位。上市前已经观察到的报告期可以在身份、观察时间和隔离证据均有效时被标为 `observed`；上市日期也不会自动补出此前或此后的报告期。

## 状态解释

### `observed`

`observed` 只表示：存在截至 `as_of_utc` 有效、适用于该报告期且没有冲突的精确身份 crosswalk，并且调用方提供了至少一个与该精确槽位匹配、观察时间和证据时间不晚于 `as_of_utc`、隔离状态为 `clear` 且有截至该时点隔离证据的版本。它表示记录存在。

该状态不依赖发行人报告生命周期证据，也不证明发行主体或来源有效、报表科目齐全、映射完整、修订历史完整或数据符合点时要求。披露日期不代替 `observed_at_utc`。

### `missing_confirmed`

只有同时满足以下条件，函数才会对一个精确槽位返回 `missing_confirmed`：

- 有截至 `as_of_utc` 有效的精确预期义务声明，且其来源、源标的、证券、报表类型、周期和报告期全部与槽位一致。
- 有单独的到期证据，到期时刻已到，并且该证据明确绑定到上述义务。
- 有截至 `as_of_utc` 有效的扫描快照；快照不早于到期时刻，扫描证据时间不早于快照。
- 扫描声明覆盖精确槽位及其快照 crosswalk，分页游标已耗尽，失败页、未解析行、隔离行和歧义 crosswalk 数量均为零。
- 有单独声明且截至评估时点有效的来源历史边界，证明来源历史范围覆盖所请求的报告期。
- 扫描返回的 `matched_version_ids` 与该槽位提供的版本 ID 完全一致；空元组表示明确扫描到零条记录，`None` 表示扫描清单未知。已观察版本也必须不晚于快照。
- 不存在任何已提供但不可用的版本（包括隔离状态未知/不清、范围不匹配或缺少必要证据的版本），也不存在冲突的槽位、版本或身份映射声明；没有未来必要证据阻断缺失结论。

即使所有字段满足上述检查，这仍是对调用方声明的条件式评估，并非函数独立验证过的缺失事实。单靠行数为零、最近扫描结果或来源当前返回范围不能确认缺失。

### `unknown`

当身份映射缺失、无效、重叠或指向多个证券，必要证据缺失或时间戳未知，必要的观察、身份或隔离证据发生在 `as_of_utc` 之后，或用于缺失结论的必要证据发生在 `as_of_utc` 之后，到期未到，扫描不完整、有错误、包含隔离或未解析行，来源历史边界未知，或扫描清单与版本列表不一致时，结果为 `unknown`。用于缺失结论的未来生命周期、到期或扫描证据不会改变已有有效观察的 `observed` 结果。相互冲突的重复槽位或版本也会使受影响的槽位保持未知。

## 证据与隐私边界

证据引用、到期义务、生命周期、扫描完整性、来源历史边界和隔离结论都是调用方声明。函数只检查结构、身份关系及时间关系，不打开引用、不访问数据库或外部 API，也不验证声明来源。返回对象固定标明 `evidence_references_independently_verified=False` 与 `point_in_time_guarantee=False`；返回中没有聚合的报表完整性结论。

`slot_ref` 和 `version_refs` 是无盐 SHA-256 指纹。它们可能可被猜测、关联或跨结果链接，因此只是稳定的伪名，**不是匿名化**。不要把原始标的、供应商响应、凭证或敏感证据路径放进引用字段或日志。

## 部署和覆盖范围

该评估器不连接数据库、不触发采集、不连接 REST 路由或定时任务，也不证明全 A 股、任何全市场范围或任何来源的历史覆盖。调用方如要生成评估输入，必须先独立建立精确的义务、截止时间、身份、扫描和历史边界证据；缺少这些证据时应保留 `unknown`，不得从上市日期或现存行反推并补造报告期。
